# byoh-solo-developer

A personalized AI agent harness generated by [BYOH](https://github.com/epicsagas/BuildYourOwnHarness).

This directory contains the polyglot (Claude Code + Codex + Antigravity) plugin and is ready to `git init && git push`.

## Install

Clone this repo into your host tool's plugin location, or follow the host's plugin-install flow:

- **Claude Code**: the `.claude-plugin/` manifest is auto-discovered.
- **Codex**: the `.codex-plugin/` manifest + `.codex/` config are auto-discovered.
- **agy (Antigravity)**: `agy plugin install <this-dir>` (the `plugin.json` marker + skills/agents/hooks.json/mcp_config.json are staged under `~/.gemini/config/plugins/`).
